# Como publicar esta versão no GitHub Pages

## O que já foi incluído
- Oito páginas SEO para marcas e categorias.
- Botões de orçamento pelo WhatsApp.
- Títulos e descrições individuais para o Google.
- Perguntas frequentes em cada página.
- `sitemap.xml` e `robots.txt`.
- Correção para abrir URLs internas no GitHub Pages.
- Links para páginas especiais no rodapé.

## Publicação pelo GitHub
1. Extraia este arquivo ZIP.
2. Abra a pasta extraída.
3. Envie todos os arquivos para o repositório `catalogo-gildene-climatizacao`, substituindo os antigos.
4. No GitHub, abra **Settings > Pages**.
5. Confirme que a publicação está configurada para o projeto correto.
6. Aguarde a implantação terminar e abra o site.

## Testar no computador
1. Instale o Node.js.
2. Abra a pasta no VS Code.
3. Abra o Terminal.
4. Execute `npm install`.
5. Execute `npm run dev`.
6. Abra o endereço exibido no terminal.

## Depois da publicação
Cadastre o site no Google Search Console e envie:
`https://gildene-droid.github.io/catalogo-gildene-climatizacao/sitemap.xml`
