CATÁLOGO GILDENE SOLUÇÕES EM CLIMATIZAÇÃO

1. Coloque as imagens oficiais dentro das pastas em images/produtos/marca/.
2. Não deixe o AI Studio gerar imagens.
3. Use sempre object-fit: contain para evitar deformação.
4. Para adicionar produto, edite js/produtos.js e coloque o caminho da imagem.
5. No GitHub, suba essa pasta inteira para o repositório.

Prompt para usar no Google AI Studio:
Não altere, gere, redesenhe ou edite nenhuma imagem. Use exatamente os caminhos de imagem existentes no arquivo produtos.js. Altere somente layout, HTML, CSS e JavaScript. Todas as imagens devem manter proporção original usando object-fit: contain.
