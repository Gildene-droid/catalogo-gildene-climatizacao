# Gildene Climatização – Versão 2.0

## O que foi incluído
- Projeto React/Vite completo.
- Catálogo, filtros, carrinho e calculadora de BTUs preservados.
- Páginas SEO para Midea, LG, Samsung, Gree, VRF, Split Inverter, residencial e comercial.
- Botões de orçamento pelo WhatsApp.
- Sitemap, robots.txt e página 404 para GitHub Pages.
- Links do Instagram atualizados para @gildeneclimatizacao.
- Configuração pronta para o repositório `catalogo-gildene-climatizacao`.

## Testar no computador
1. Instale Node.js.
2. Abra esta pasta no VS Code.
3. No terminal, execute: `npm install`
4. Depois execute: `npm run dev`

## Gerar a versão publicada
Execute: `npm run build`
A pasta `dist` será criada.

## Publicar no GitHub Pages pelo navegador
A maneira mais simples é enviar o conteúdo da pasta `dist` para o repositório que publica o site. Não envie a pasta `dist` fechada: envie os arquivos que estão dentro dela.
